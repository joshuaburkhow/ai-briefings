ANTHRO

An unreleased Claude model pushed a 37-year-old Riemann Hypothesis bound from 41.6% to 67.2%, the biggest single jump in the problem's history.

  • Told to take a real stab at the Riemann Hypothesis, Claude failed to solve it but improved the proven lower bound on zeros that satisfy it from 41.6% to 67.2% — a 25-point leap after the field had gained under one point in 37 years.AlphaSignal
  • It ran roughly 60 subagents in parallel inside Claude Code, tried about 650 failed ideas, and executed 2,400 shell commands over a day and a half, burning 31 million output tokens.genai.works
  • The proof was rewritten in Lean 4 for machine verification and reviewed by two external mathematicians, including Brian Conrey, who set the 1989 record it beat.TLDR AI
  • The prompt author, Anthropic's Jarred Sumner, is not a mathematician and mostly typed encouragement like 'keep going'; the model stays unreleased but the proof code and logs are public.The Neuron Daily
Why it matters

AI is starting to extend, not just recite, human research. A general-purpose model coordinating subagents advanced a frontier math result that specialists had barely moved in decades, hinting that agentic setups can do real discovery work today even before a model ships.

Anthropic will embed invisible watermarks in Claude-generated text and C2PA metadata in Claude images to comply with EU transparency rules.

  • Claude's text output will carry imperceptible watermarks and its images will use C2PA provenance metadata, designed to let platforms detect AI-generated content without affecting readability.Brain Buzz

Provenance is becoming a default, not an option. If a frontier lab hard-codes detectable signatures into everything it generates, AI-content labeling shifts from voluntary experiment to shipped feature — with real friction for developers who treat model output as their own.

Concepts to know

C2PA metadata
Brain Buzz

An open provenance standard (Coalition for Content Provenance and Authenticity) that attaches tamper-evident 'nutrition label' data to a file recording how it was made — here, marking that an image came from Claude.

Post-transformer architecture
The Deep View

A model design that departs from the standard transformer, using different memory mechanisms to reason with far fewer parameters and no chain-of-thought; Pathway's BDH-CQ is an early example aimed at cutting compute cost.

Zero-day
AlphaSignal

A software security flaw that is unknown to the vendor and has no patch yet, so defenders have 'zero days' to prepare — the class of bug OpenAI's GPT-5.6-Cyber was built to find.

Open-weight model
The Neuron Daily

A model whose trained parameter files are published so anyone can download, run and modify it on their own hardware, rather than only calling it through the maker's servers.
