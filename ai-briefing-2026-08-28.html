That's the same efficiency-over-scale argument Chinese labs have been making all year, and it lands the same week Hugging Face — the platform that hosts these open-weight releases — is being bought outright by Nvidia.

Gemini 3.5 Transcribe Uses What's on Your Screen to Type What You Say

  • Google introduced Gemini 3.5 Transcribe, calling it its most precise speech-to-text model yet; it powers Rambler on Android and the Gemini app on macOS, converting raw audio into accurate, polished, formatted text.The Deep View
  • With permission, the model can combine spoken input with screen context and chat history to better recognize file names, agent thoughts, active documents, and other context-specific terms inside Google Antigravity.AI Entrepreneurs

Concepts to know

Cognitive Memory Agent
TLDR AI

LinkedIn's architecture for personalizing its hiring assistant using four memory layers — conversational, episodic, semantic, and procedural — replacing GraphRAG with a hierarchical tree that supports cheaper incremental updates, with dedicated services keeping preferences fresh, traceable, and access-controlled within tight latency limits.

Manifold-Constrained Hyper-Connections
The Deep View

A technique Z.ai used in GLM-5.3-Flash to improve how information moves through a neural network's layers, which the company says boosts scaling efficiency and helped the model outperform its predecessor at a tenth of the serving cost.

Semantic Code Navigation (code graph)
Turing Post

An approach where a coding agent queries a structural graph of a codebase (which method calls which, what implements what) instead of relying on text search. In a controlled study cited by Turing Post, giving an agent this capability cut task cost by 5–36% on changes that had to land identically across every implementation of a shared interface, without hurting cost on tasks where search wasn't the bottleneck.
