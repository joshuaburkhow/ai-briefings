  • Zenity Labs described a new vulnerability class hijacking agentic browsers, chained into zero-click account takeover, data theft and remote code execution.TLDR AI
  • A separate technique planted a fully autonomous attacker-controlled agent inside a victim's organisation from one crafted link, before OpenAI patched it.TLDR AI

Concepts to know

Zero-click attack
TLDR AI

An exploit needing no action from the victim. In an agentic browser the agent itself follows the link, so the user's caution never enters the chain.

Mixture of experts
TLDR AI

An architecture where only a fraction of parameters activate per token. Inkling-Small is 276B parameters with 12B active, so it serves closer to the cost of a small model.

Self-optimisation
AINews

Using a model to analyse and improve its own serving. OpenAI used GPT-5.6 Sol on production traffic, which is part of why prices fell this far.
