Concepts to know

AA-Briefcase
The Neuron

An Artificial Analysis agentic benchmark that scores a model on completing long knowledge-work tasks, and reports the turns and tokens it took. It is why Grok 4.6 can look cheaper than a rival at the same quality: fewer turns means less spend for the same finished job.

Open weights
AI Entrepreneurs

A model whose trained parameters are published so anyone can download and run it. Qwen3.8's 2.4 trillion parameters are open weights — not the same as open source, since the training data and code are not included.

Active parameters
AINews

In a mixture-of-experts model, the slice of parameters actually used for any one token. Qwen3.8 is 2.4T total but only 95B active, so it costs far less to run than its headline size suggests.

Forward deployed partner
The Deep View

A consulting firm trained and certified to install a vendor's AI inside customers' systems. OpenAI is renting IBM's consultants rather than hiring thousands of its own.

Agent identity
Turing Post

Giving each running agent its own credential tied to a named human owner, instead of a shared service account. It is what makes it possible to say who authorised an action after the fact.
