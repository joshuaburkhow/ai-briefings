An AI-Designed Cancer Therapy Just Cleared Phase 3

  • Merck and Moderna reported the first positive Phase 3 result for an individualized mRNA cancer therapy, intismeran autogene, in the INTerpath-001 melanoma trial.The Neuron
  • Moderna's AI algorithms read sequencing data from a patient's tumor and blood, scan the cancer's mutations, and predict up to 34 'neoantigens' most likely to trigger an immune response, which are then encoded into a custom mRNA dose for that patient.The Neuron
  • Paired with Keytruda, the personalized therapy significantly improved recurrence-free and distant-metastasis-free survival versus Keytruda alone; overall-survival follow-up is still ongoing.The Neuron
Why it matters

This is a concrete clinical result, not a lab demo. Phase 3 data is the threshold regulators and doctors actually act on. An AI pipeline choosing which mutations to target, one patient at a time, and clearing that bar is a rare case of frontier AI directly changing what a doctor can offer a patient today.

Z.ai Says GLM-5.3's Jump Came From Training, Not Size

  • Z.ai CEO Jie Tang argued raw parameter count is no longer a useful shorthand for capability, saying it only means something alongside training data volume, compute allocation, and deployment conditions.AINews
  • GLM-5.3's largest capability jumps came entirely from reinforcement learning on long-horizon, production-style task environments — some representing several days of real engineering work — rather than from a bigger base model.AINews
  • To scale that training, Z.ai built pipelines that synthesize entire task environments end-to-end, including verifiers that check a task is genuinely solvable without ever seeing the reference solution.AINews
Why it matters

This is an explicit break from the scaling-law playbook the whole industry has cited for years. If long-horizon RL environments, not parameter count, are what's driving the next round of capability gains, that changes where labs — including Chinese labs racing on tighter compute budgets — should be spending their next dollar.

Snowflake Joins the Rush to Route AI Requests to Cheaper Models

  • Snowflake added dynamic model routing to its Cortex AI Gateway and its Snowflake CoCo/CoWork products, automatically sending each task to the cheapest model that can still handle it.The Deep View
  • In Snowflake's internal tests, agents building a dbt data pipeline saw up to 3x greater token efficiency with routing versus a frontier-model-only path, without a quality drop; a separate coding test found 25% greater token efficiency at the same PR output.The Deep View
  • The move follows Nvidia's own open-source NeMo Switchyard router, and comes as a Gartner forecast cited in the same report projects AI inference cost per agentic workflow to more than quintuple through 2028.The Deep View
Why it matters

Model routing is turning into the default answer to the industry's cost problem. As agentic workflows multiply the number of model calls per task, routing to the cheapest adequate model — rather than defaulting to the frontier model for everything — is becoming table stakes rather than a niche optimization.

Concepts to know

Context Engineering
AI Corner

The discipline of deliberately budgeting what an AI agent sees at each step — which instruction files load when, what survives a context compaction — rather than front-loading everything into the prompt. Anthropic's engineering org cited it as the main driver behind engineers merging 8x more code per day than in 2024, with the model and team otherwise unchanged.

Private Safety Processing
AI Entrepreneurs

OpenAI's proposed system for detecting harmful usage patterns across related API interactions for Zero Data Retention customers, without giving OpenAI staff access to the underlying prompts or responses — automated safety signals instead of stored, human-reviewable content.

Physical Prompting
The Neuron

A robot-learning technique from Generalist's GEN-1.5 model: showing a robot a single 3-12 second video demonstration of a task, which it holds in a 30-second context window and immediately attempts, with zero gradient updates. Ten weight-update steps on five minutes of data raised success on simple tasks from 59% to 83%.
