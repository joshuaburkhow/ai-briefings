  • Z.ai's GLM-5.3 gained a 50% coding-benchmark boost over GLM-5.2 through post-training alone on the same base model, hit state-of-the-art on the CyberGym security benchmark, and will open its weights after more safety testing.AI Entrepreneurs

That matters for anyone choosing between API models and self-hosted ones: the cost/performance gap keeps narrowing.

OpenAI Cuts Off Cursor's API Access After Its SpaceX Acquisition

  • OpenAI shut off Cursor's access to its models following the close of Cursor's acquisition by Elon Musk's SpaceX, citing "our experience with Elon Musk's companies violating contracts."AINews
  • Cursor says OpenAI traffic was only about 5% of its usage and is not treating the cutoff as necessarily final; it can lean on GPT-5.6, Grok 4.6, or Claude for coding instead.AINews
Why it matters

This mirrors what Anthropic did to Windsurf when it was up for sale to OpenAI, and shows model access is now a competitive weapon. As coding tools get acquired by rival AI labs' backers, the underlying model providers are willing to cut them off rather than keep subsidizing a competitor's product. It's a sign the coding-agent market is now split along lab allegiance lines, not just feature sets.

Concepts to know

Open-weight model
AI Entrepreneurs / AINews

An AI model whose trained parameters are published for anyone to download and run locally or self-host, rather than being accessible only through a paid API from the lab that built it.

Mixture of Experts (MoE)
AINews

A model architecture where only a subset of the model's total parameters, called experts, activate for any given input. This lets a huge model like Hy4-preview (770B total parameters) run at roughly the cost of a much smaller one (49B active).

Speculative decoding
AINews

An inference speedup technique where a small, fast draft model predicts several tokens ahead and the main model verifies them in one pass instead of generating one token at a time. vLLM's benchmarking found no single method wins across all model families.
